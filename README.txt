RÉPERTO’POCHE — VERSION CORRIGÉE

Application web installable (PWA) pour iPhone, iPad et Mac.

CORRECTIONS DE CETTE VERSION
- les rubriques Protocoles, Langues étrangères et Notes rapides s’ouvrent correctement ;
- ajout de nouvelles entrées dans ces trois rubriques ;
- modification ou suppression sans bouton visible sur les fiches : maintenir une entrée appuyée environ une seconde, puis choisir Modifier ou Supprimer ;
- même geste appliqué aux médicaments, établissements, contacts et créneaux de planning ;
- mise à jour automatique du cache de l’application après publication.

MISE À JOUR SUR GITHUB PAGES
Il n’est pas nécessaire de désinstaller ni de réinstaller l’application sur l’iPhone.

1. Remplacer le contenu du dépôt GitHub Pages par les fichiers de cette version.
2. Attendre la fin de la publication GitHub Pages.
3. Ouvrir Réperto’Poche installée sur l’iPhone, puis la fermer et la rouvrir une fois.

Les données créées restent enregistrées localement sur l’appareil. Elles ne sont pas envoyées à un serveur.
