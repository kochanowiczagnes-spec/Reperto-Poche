RÉPERTO’POCHE — MISE À JOUR v15

Application web installable (PWA) pour iPhone, iPad et Mac.

CORRECTIONS DE CETTE VERSION
- un fichier peut être joint à une fiche de médicament, un établissement, un contact, un créneau de planning, un protocole, une note, un dossier de langue ou une note de langue ;
- le bouton « Ouvrir le fichier » utilise l’aperçu/lecteur d’iPhone lorsque le format est compatible ; les formats non pris en charge restent proposés par iOS au partage ou au téléchargement ;
- les liens de fichiers ne déclenchent plus l’appui prolongé de la fiche par erreur ;
- lors d’une modification sans nouveau fichier, le fichier déjà joint est conservé ;
- la limite est de 2 Mo par fichier ;
- les rubriques Protocoles, Langues étrangères et Notes rapides s’ouvrent correctement ;
- une nouvelle version de cache force l’actualisation de l’application après publication.

DONNÉES PRÉSERVÉES
Les six collections locales existantes (médicaments, établissements, planning, langues, protocoles et notes) ne sont ni supprimées ni migrées. Les données créées restent enregistrées uniquement sur l’appareil.

MISE À JOUR SUR GITHUB PAGES
Il n’est pas nécessaire de désinstaller ni de réinstaller l’application sur l’iPhone.

1. Décompresser l’archive et remplacer le contenu du dépôt GitHub Pages par les fichiers du dossier Réperto-Poche.
2. Attendre la fin de la publication GitHub Pages.
3. Ouvrir Réperto’Poche installée sur l’iPhone, puis la fermer complètement et la rouvrir une fois.
4. Vérifier l’ouverture d’un fichier existant, par exemple « Tableau des antibiotiques.pdf ».

Les fichiers et données restent locaux ; ils ne sont pas envoyés à un serveur.
